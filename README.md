# 简效利润计算器（免费版）

> 简效工具实验室 · 面向国内小卖家的一款免费、开源、纯前端利润测算工具。

输入商品标价、促销折扣、采购成本、卖家承担的运费、包装费用、营销费用及按比例收取的各类费用，实时计算：

- **单笔订单预计净利润**与按折后实收计算的净利率
- **折后实收金额**与成本构成
- **保本最低标价**
- 达到指定**目标净利润**所需的理论标价
- 一键复制计算结果；手机和电脑均可使用

## 如何使用

**方法一：本地运行**

1. 下载本仓库的 [`index.html`](./index.html)。
2. 双击文件，用 Chrome、Edge 或其他现代浏览器打开。
3. 修改示例数字即可看到结果。不需要登录，也不需要联网。

**方法二：GitHub Pages**

仓库创建者可在 **Settings → Pages → Build and deployment** 中将源设置为 `Deploy from a branch`，选 `main` 和 `/(root)`。等待部署完成，即可通过 Pages 地址访问。

## 计算逻辑

```text
折后实收 = 商品标价 × (1 − 促销折扣率)
固定成本 = 采购/制作成本 + 卖家承担的运费 + 包装成本 + 单笔营销及其他成本
比例费用 = 折后实收 × (平台费率 + 支付服务费率 + 售后损耗预留比例)
单笔净利润 = 折后实收 − 固定成本 − 比例费用
净利率 = 单笔净利润 ÷ 折后实收
保本标价 = 固定成本 ÷ [(1 − 折扣率) × (1 − 合计比例费率)]
目标利润标价 = (固定成本 + 目标净利润) ÷ [(1 − 折扣率) × (1 − 合计比例费率)]
```

**说明：** 示例费率纯属虚构，不代表任何平台真实收费；按比例收取的费用假设以折后实收为基数。售后损耗预留是比例缓冲，并不代表完整的退款概率模型。未单独考虑税费、退货运费、阶梯费率、最低扣费、平台活动补贴等复杂情况，请使用真实业务数据核对。
